# Telegram-бот для заказов и дедлайнов

Бот на [aiogram 3](https://docs.aiogram.dev/) для учёта заказов с дедлайнами, напоминаниями и архивом. Данные хранятся в **PostgreSQL**, фоновые задачи выполняет **APScheduler**.

## Возможности

- **Новый заказ** — пошаговое создание: название, описание (по желанию), дата и время дедлайна через календарь и кнопки времени. До **50 активных** заказов на пользователя.
- **Мои заказы** — список активных заказов с дедлайнами и статусами (активный, скоро, просрочен).
- **Напоминания** — за 24 часа, 3 часа и 1 час до дедлайна, в момент дедлайна; для просроченных — периодические уведомления. Настраиваются в профиле.
- **Настройки** — часовой пояс, включение/выключение каждого типа напоминаний, размер страницы списков.
- **Архив** — завершённые и отменённые заказы за последние **90 дней** (старые записи удаляются планировщиком).
- **Администратор** — пользователи из `ADMIN_IDS` видят пункт «Статистика» (число пользователей, активных заказов, завершённых за месяц, просроченных).

Интерфейс на русском языке, управление через inline-кнопки и команды.

## Требования

- Python 3.10+
- PostgreSQL
- Токен бота от [@BotFather](https://t.me/BotFather)

## Установка

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Создайте базу данных в PostgreSQL и скопируйте пример переменных окружения:

```bash
cp .env.example .env
```

Заполните `.env` (см. раздел ниже).

## Переменные окружения

| Переменная | Описание |
|------------|----------|
| `BOT_TOKEN` | Токен Telegram-бота |
| `ADMIN_IDS` | ID администраторов в Telegram через запятую (например `123456789,987654321`) |
| `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD` | Параметры подключения к PostgreSQL |
| `DEFAULT_TIMEZONE` | Часовой пояс по умолчанию для новых пользователей (по умолчанию `Europe/Moscow`) |
| `REMINDER_CHECK_INTERVAL` | Интервал в секундах между проверками напоминаний и обновлением статусов (по умолчанию `60`) |

При первом запуске таблицы `users`, `orders` и `reminders_log` создаются автоматически.

## Запуск

```bash
python main.py
```

Бот работает в режиме **long polling** (вебхук очищается при старте).

## Структура проекта

| Путь | Назначение |
|------|------------|
| `main.py` | Точка входа: бот, роутеры, БД, планировщик |
| `config.py` | Настройки из `.env` (pydantic-settings) |
| `db.py` | Пул asyncpg и инициализация схемы |
| `handlers/` | Обработчики: меню, заказы, создание, архив, настройки, админ, планировщик |
| `utils/` | Клавиатуры, FSM-состояния, модели статусов, сервисные функции |

## Зависимости

- `aiogram` — Telegram Bot API
- `asyncpg` — асинхронный драйвер PostgreSQL
- `APScheduler` — периодические задачи (напоминания, очистка архива)
- `pydantic-settings` — загрузка конфигурации
